# statebloom

This package is a **name placeholder**. It contains no code and is not meant to be installed as a
dependency.

StateBloom is published under the **`@statebloom` scope**. There is nothing to import from the bare
`statebloom` name, and there are no plans for there to be — this package exists so that the obvious
name adjacent to the project's real packages stays under the project's control.

## Where the actual packages live

The framework is still in development and its packages are not yet published. When they are, they
will appear under `@statebloom/*` — for example `@statebloom/core`, `@statebloom/runtime`, and
`@statebloom/ui`.

Until then, see <https://github.com/statebloom/statebloom>.
